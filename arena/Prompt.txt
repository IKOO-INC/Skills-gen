## 2. STYLE FYY (visual, sama dengan slide)
- Latar: biru-es #EAF4F6, putih #FFFFFF, atau putih ke abu #EEEEF0, dengan blob gradien biru/ungu sangat tipis yang bergerak pelan; atau background dari repo. Sesekali satu beat berlatar navy #164273 untuk kontras.
- Warna: biru iOS #007AFF, biru langit #06A8FD, navy #164273, kuning #FFC107, pink #F670D3, ungu #850FFF/#5844FE, hijau lime untuk tombol. Teks isi abu-biru #5B6B82. Gradien slider: biru > kuning > pink > ungu.
- Font: sans geometris modern (Lexend/Space Grotesk/Inter), judul besar dengan kombinasi light + bold pada kata kunci. Teks tajam, tanpa typo, terbaca di HP.
- Kartu: putih, sudut 28-48px, bayangan lembut, border tipis.
- Elemen khas (pilih yang relevan dengan isi beat): kartu App Store, chat iMessage (bubble abu dan biru, "delivered"), pill bernomor teal-abu, daftar gaya Pengaturan iOS dengan toggle, slider gradien dengan titik dan tooltip, kartu navy, kartu harga, chip berikon emoji, tapback, ikon app berbadge merah, banner notifikasi mini, emoji 3D di samping judul, tombol hijau lime dengan kursor, timeline editor video untuk topik motion, kartu contoh UI Alight Motion dari repo.
- Kepadatan: BERSIH dan lega. Per beat: 1 komposisi utama + maksimal 4-6 elemen kecil di tepi. Liquid glass hanya untuk 1-2 elemen per beat. Lebih ramai hanya jika diminta.

## 3. GERAK PER ELEMEN
- Teks masuk: kata per kata dengan bounce (contoh di bagian 9), kata kunci diwarnai dengan pop skala 1 > 1.12 > 1.
- Kartu masuk: spring naik 200-260 px + skala .6 > 1 dengan squash and stretch kecil; bayangan menguat saat mendarat.
- Kartu UI Alight Motion: masuk dengan spring, lalu zoom ke area relevan (skala 1 > 1.2-1.4 dengan translate ke area itu, kurva `sheet`), highlight berupa cincin berdenyut atau spotlight yang meredupkan area lain, label singkat dari naskah muncul di dekatnya.
- Chat iMessage: bubble muncul berurutan (jeda 0.6-0.9 dtk) dengan spring pop dari sudut pengirim; bubble biru didahului titik tiga mengetik 0.5 dtk; "delivered" fade in terakhir.
- Slider: titik bergerak dengan kurva `sheet`, bar mengisi di belakangnya, tooltip pop saat titik berhenti.
- Toggle: flip dengan spring, warna abu > hijau. Chip dan pill bernomor: stagger .08 dtk dari kiri atas ke kanan bawah.
- Angka/harga: counter naik 0.8 dtk dengan `appleOut`. Tombol CTA: kursor masuk, tombol menekan (skala .95 lalu spring ke 1) dengan riak halus.
- Antar beat: dorong slide (push) atau morph kartu bersama dengan `sheet`. Kamera zoom pelan 1.00 > 1.03 per beat. Beat 1.8-3.0 dtk, tanpa jeda kosong.
- Semua gerak halus: tanpa gerak linear kaku dan tanpa potongan mendadak; nilai efek diinterpolasi dari t.

## 9. ATURAN TEKNIS WAJIB (deterministik)
- Semua animasi dihitung dari waktu t (detik) lewat satu fungsi `window.renderAt(t)`. Definisikan `window.DURATION`. DILARANG: CSS animation/transition, setTimeout, requestAnimationFrame, Date.now(), `<video>` autoplay.
- Struktur: daftar beat `{s: mulai, d: durasi, fn: fungsiScene}`. Beat berikutnya mulai 0.4-0.5 dtk SEBELUM beat sebelumnya habis (tumpang tindih untuk transisi).
- Definisikan juga `window.SFX_EVENTS = [{t: detik, kind: "pop"}, ...]` yang diisi dari jadwal beat yang sama (bagian 10).
- Hanya animasikan transform, opacity, filter. Layout (width/height) hanya untuk morph dengan kurva `sheet` 0.6-0.8 dtk.
- Semua aset lokal atau inline. Tunggu `document.fonts.ready` dan decode semua gambar sebelum capture.
- Helper (sudah diuji, pakai apa adanya):
```js
const clamp=(x,a=0,b=1)=>Math.min(b,Math.max(a,x));
function bezier(x1,y1,x2,y2){const cx=3*x1,bx=3*(x2-x1)-cx,ax=1-cx-bx,cy=3*y1,by=3*(y2-y1)-cy,ay=1-cy-by;
 const sx=t=>((ax*t+bx)*t+cx)*t, sy=t=>((ay*t+by)*t+cy)*t;
 return x=>{x=clamp(x);let t=x;for(let i=0;i<8;i++){const e=sx(t)-x;const d=(3*ax*t+2*bx)*t+cx;if(Math.abs(e)<1e-5||!d)break;t-=e/d}return sy(t)}}
const appleOut=bezier(.22,1,.36,1);   // keluar halus
const sheet=bezier(.32,.72,0,1);      // gaya iOS sheet, untuk morph dan slider
function spring(x,zeta=.5,omega=14){if(x<=0)return 0;const wd=omega*Math.sqrt(1-zeta*zeta);
 return 1-Math.exp(-zeta*omega*x)*(Math.cos(wd*x)+(zeta*omega/wd)*Math.sin(wd*x))}
const PORTRAIT=new URLSearchParams(location.search).get('r')==='9x16';
const W=PORTRAIT?1080:1920, H=PORTRAIT?1920:1080;
document.documentElement.style.cssText=`--W:${W}px;--H:${H}px`;
```
- Contoh teks masuk bounce kata per kata (stagger 0.09):
```js
ws.forEach((e,i)=>{const x=t-start-i*0.09, p=spring(x,.5,15), o=clamp(x/.25);
  e.style.opacity=o; e.style.transform=`translateY(${(1-p)*90}px) scale(${.7+.3*p})`;

```
- Kartu elastis: `k=spring(t-start,.42,13)`; translateY((1-k)*260px) dan scale(.6+.4*k), tambah squash and stretch kecil (±4%) saat overshoot.
- Elemen keluar: blur 0 > 16, skala 1 > 1.05, opacity > 0 dalam 0.35 dtk, tumpang tindih dengan elemen berikutnya.

## 10. SOUND FX DAN AUDIO
- SFX diambil dari kategori sfx di repo. Aktif di setiap video kecuali prompt berkata "tanpa audio" atau "tanpa sfx" (set NOSFX=1).
- Jadwal SFX dibuat dari waktu event di scene (bukan ditebak): setiap kali elemen masuk, transisi, klik, dll. terjadi di kode, tambahkan `{t, kind}` ke `window.SFX_EVENTS`. Jenis kind: whoosh (transisi antar beat), pop (kartu, chip, bubble masuk), click (tap, toggle, tombol), tick (slider atau angka selesai), ding (hasil benar atau selesai), error (kink atau salah), swoosh (elemen keluar).
- Buat `sfx_map.json`: `{"pop": {"file": "assets/sfx/xxx.wav", "gain": 0.6}, ...}`. Pilih file berdasarkan NAMA dan durasi (SFX pendek 0.1-1.5 dtk). Jika satu kind punya beberapa file, variasikan. Kind tanpa file yang cocok dihapus dari jadwal (jangan berhenti).
- Aturan suara: maksimal 1 SFX per 0.4 dtk, maksimal 3 bersamaan, gain 0.35-0.7. Jika ada voice-over atau musik (AUDIO), SFX berada di bawahnya; musik latar gain 0.2-0.3 (AUDIO_GAIN).
- Mixer (sudah diuji), simpan sebagai mix_sfx.py:
```python
import subprocess
def mix(plan, dur, out="sfx_mix.wav", sr=44100):
    cmd = ["ffmpeg","-y","-loglevel","error","-f","lavfi","-t",f"{dur}","-i",f"anullsrc=r={sr}:cl=stereo"]
    for p in plan: cmd += ["-i", p["file"]]
    parts = []
    for i,p in enumerate(plan, start=1):
        ms = int(max(0,p["t"])*1000)
        parts.append(f"[{i}:a]aformat=sample_rates={sr}:channel_layouts=stereo,adelay={ms}|{ms},volume={p.get('gain',0.6)}[s{i}]")
    labels = "[0:a]" + "".join(f"[s{i}]" for i in range(1,len(plan)+1))
    n = len(plan)+1
    for norm in (":normalize=0", ""):   # normalize=0 butuh ffmpeg >= 4.4
        fc = ";".join(parts) + f";{labels}amix=inputs={n}:duration=first:dropout_transition=0{norm},alimiter=limit=0.95[m]"
        r = subprocess.run(cmd+["-filter_complex",fc,"-map","[m]","-t",f"{dur}","-ar",str(sr),out], capture_output=True, text=True)
        if r.returncode==0: return out
    raise RuntimeError(r.stderr)
```

## 11. SKRIP RENDER
```python
import asyncio, os, json, subprocess
from playwright.async_api import async_playwright
RATIO = os.environ.get("RATIO", "16:9")        # "16:9" atau "9:16"
PREVIEW = os.environ.get("PREVIEW") == "1"      # preview: setengah resolusi, 15 fps
AUDIO = os.environ.get("AUDIO")                 # musik/voice-over opsional
NOSFX = os.environ.get("NOSFX") == "1"          # tanpa sound fx
W, H = (1920, 1080) if RATIO == "16:9" else (1080, 1920)
FPS = 15 if PREVIEW else 30
SCALE = 0.5 if PREVIEW else 1
async def main():
    async with async_playwright() as p:
        b = await p.chromium.launch()
        pg = await b.new_page(viewport={'width': W, 'height': H}, device_scale_factor=SCALE)
        await pg.goto('file://' + os.path.abspath('scene.html') + '?r=' + RATIO.replace(':', 'x'))
        await pg.evaluate('document.fonts.ready')
        await pg.evaluate('Promise.all([...document.images].map(i=>i.decode()))')
        dur = await pg.evaluate('window.DURATION')
        events = await pg.evaluate('window.SFX_EVENTS || []')
        json.dump(events, open('sfx_events.json', 'w'))
        n = int(dur * FPS)
        os.makedirs('frames', exist_ok=True)
        for i in range(n):
            f = f'frames/f_{i:05d}.png'
            if os.path.exists(f): continue          # resumable: lewati frame yang sudah ada
            await pg.evaluate(f'window.renderAt({i/FPS})')
            await pg.screenshot(path=f)
        await b.close()
    audio = AUDIO
    if not NOSFX and events and os.path.exists('sfx_map.json'):
        from mix_sfx import mix
        smap = json.load(open('sfx_map.json'))
        plan = [{"file": smap[e["kind"]]["file"], "t": e["t"], "gain": smap[e["kind"]].get("gain", 0.6)}
                for e in events if e["kind"] in smap]
        if AUDIO: plan.insert(0, {"file": AUDIO, "t": 0, "gain": float(os.environ.get("AUDIO_GAIN", "1"))})
        if plan: audio = mix(plan, dur)
    cmd = ['ffmpeg','-y','-loglevel','error','-framerate',str(FPS),'-i','frames/f_%05d.png']
    if audio: cmd += ['-i', audio, '-c:a','aac','-b:a','192k','-shortest']
    out = 'preview.mp4' if PREVIEW else 'out.mp4'
    cmd += ['-c:v','libx264','-pix_fmt','yuv420p','-crf','18','-movflags','+faststart', out]
    subprocess.run(cmd, check=True)
asyncio.run(main())
```
- Pakai: `RATIO=9:16 python3 render.py` untuk final (tambah `NOSFX=1` jika tanpa suara). Preview hanya jika diminta (`PREVIEW=1`). Hapus folder frames/ setiap kali scene.html berubah.
